# Vice Cover Studio

Vice Cover Studio is an original offline poster maker built for the make.fun gta6-cover-art-01 bounty: turn local photos into cinematic, neon-soaked multi-panel cover art and export it straight to PNG.

[![rank](https://make.fun/badge/gta6-cover-art-01/GhalyRisyadi/gta6-cover-art-01/rank.svg)](https://make.fun/bounty/gta6-cover-art-01/leaderboard?utm_source=github&utm_medium=readme&utm_campaign=gta6-cover-art-01)
[![reward](https://make.fun/badge/gta6-cover-art-01/GhalyRisyadi/gta6-cover-art-01/reward.svg)](https://make.fun/bounty/gta6-cover-art-01?utm_source=github&utm_medium=readme&utm_campaign=gta6-cover-art-01)

Run `node serve.ts`, then open http://localhost:8080.

Features: local multi-photo import and drop zone; five poster cuts; per-panel photo assignment, drag framing, and zoom; editable title, kicker, and billing; four cinematic color grades; procedural sun, palms, grain, and type effects. Export 1080×1080, 1080×1350, or 1920×1080 PNGs. Anton and Oswald font files are included under `app/assets/fonts/` with their SIL Open Font License notices. MIT licensed.
